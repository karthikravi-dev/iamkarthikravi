An exhibition of work by Karthik Ravishankar

Tools for real systems

Cisco, Bengaluru, 2024 to 2026

Eight AI tools by a consulting engineer in Cisco Customer Experience. Each one connects a model to something real: test records, routers, bug databases, a team’s own conversations. Four are on show in full; the rest hang in the smaller works room.

Enter the exhibitionContact the artist

Gallery 1, no. 1

SVS Pulse

2026

Python, FastAPI, PostgreSQL, React, TypeScript, MCP, an LLM (Circuit)
In production at Cisco

Started by the artist on his own and built from scratch. Every CXTM project in one view, with delivery questions answered in plain language. A Pulse MCP server brings the same answers into Claude. Its PRD is approved by CX-PM.

30–40 min → 1 clickto prepare a customer report, with about 94% fewer AI tokens. 60+ customers, 500+ projects, 26K+ test cases.

Gallery 1, no. 2

SVS One

2026

Next.js, TypeScript, PostgreSQL, Prisma, MCP, RAG
Live

One governed platform for a team’s certifications, contributions and project allocations, replacing duplicate Excel trackers that anyone could delete. Ask SVS One answers using RAG over 8.1K transcript chunks from past session recordings.

430+learning resources, searchable by asking, in Cisco Circuit and Claude Code.

Gallery 2, no. 3

Topic Search MCP

2025

Python, Podman, MCP, Cisco Topic API
Published internally

A containerised MCP server that lets an AI assistant search Cisco bug reports, Techzone articles and documentation in a single call.

Several teamsat Cisco use it.

Gallery 2, no. 4

EcoVisionaries

2026

TypeScript, Slack Bolt, PostgreSQL, pgvector
Made for CX Tech4Social Good, first runner-up

A Slack app for Work on Climate that finds the members you should meet, through five stages: intent extraction, HyDE profiles, multi-source retrieval and LLM re-ranking.

72% precisionagainst 33% for naive RAG.
