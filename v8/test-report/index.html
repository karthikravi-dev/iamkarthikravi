1.Test cases

Each tool is written up as a test case: what it is meant to do, how it was built, and the evidence that it works. Status shows where it stands today.

TC-01SVS Pulse

In production
Objective
Put every CXTM project in one view and answer delivery questions in plain language.
Built with
Python, FastAPI, PostgreSQL, React, TypeScript, MCP, an LLM (Circuit). A Pulse MCP server brings the answers into Claude and AI coding tools.
Evidence
Report prep: 30–40 minutes → one click. About 94% fewer AI tokens per report. Covers 60+ customers, 500+ projects and 26K+ test cases.
Notes
Started on his own and built from scratch. PRD approved by CX-PM. He led its booth at an internal Cisco showcase.

TC-02SVS One

Live
Objective
Replace duplicate, deletable Excel trackers for certifications, contributions and project allocations.
Built with
Next.js, TypeScript, PostgreSQL, Prisma, MCP, RAG.
Evidence
One governed platform with a QBR dashboard. Ask SVS One answers from the team’s records and 430+ learning resources, using RAG over 8.1K transcript chunks. Works in Cisco Circuit and Claude Code.

TC-04EcoVisionaries

Hackathon, 2nd
Objective
Find the members you should meet in Work on Climate, a 40,000-member Slack community.
Built with
TypeScript, Slack Bolt, PostgreSQL, pgvector. Five stages: intent extraction, HyDE profiles, multi-source retrieval, LLM re-ranking.
Evidence
72% precision against 33% for naive RAG. First runner-up, CX Tech4Social Good, 2026.
