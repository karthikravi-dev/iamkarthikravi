Hi, I’m Karthik.

I joined Cisco as an intern in January 2024 and became a consulting engineer in Customer Experience that July. Most days I work on validation for a large enterprise network, and I build the AI tools around that work.

The tool I’m proudest of is SVS Pulse. I started it on my own, built it from scratch, and it now runs in production: every project in one view, and answers in plain language. A Pulse MCP server brings the same answers into Claude and AI coding tools.

I care about AI that earns its place in someone’s week. That means MCP servers that reach real systems safely, automation that saves hours, and teaching other engineers to build the same way.
